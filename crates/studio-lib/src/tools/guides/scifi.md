# 科幻创作指导

这是科幻类型小说的专项创作要求，作为通用叙事心法的补充。通用原则（展示而非告知、章末钩子、视角锚定等）仍然适用，以下聚焦科幻特有的要点。

## 一、设定与故事的平衡

科幻的核心竞争力是"思想的戏剧"，设定必须长在冲突里。

- 一个科幻点子撑起一部长篇：围绕一个核心假设（上传意识、曲率航行、时间坍缩）穷尽它的社会后果，胜过堆砌十个互不相干的酷概念。
- 设定通过使用揭示，而非通过讲解灌输：读者跟着角色在困境中运用规则来理解规则。开篇大段设定说明书是科幻文最常见劝退点。
- 每条规则一旦确立就不可违背：科幻的悬念建立在"规则可信"之上——读者记得住你的世界怎么运转，作弊一次全盘崩塌。
- 技术要有成本与副作用：能量、伦理、社会代价让奇观落地，无成本的技术解决不了任何戏剧问题。

## 二、奇观与陌生化

科幻的美感来自"熟悉的陌生"，细节比术语更有未来感。

- 用具体可感的细节传递异世界：舱内壁凝结的水珠、合成蛋白的口感、跨光年延迟半分钟的通话——一个细节胜过十页技术名词。
- 术语密度要控制：生造词首次出现时用上下文自解释，一章新概念不超过两三个。读者跳过看不懂的段落，就会跳过这本书。
- 日常场景的未来化改写最见功力：外卖、葬礼、法庭、恋爱在未来如何变形，是科幻质感的真正来源。

## 三、硬度分寸与自洽

- 硬核与软核是光谱不是高下：选择本书的硬度档位并在开篇向读者交代（近未来技术惊悚 vs 星际歌剧）， consistency 比正确性更重要。
- 科学细节宁少勿错：不确定的领域（量子、AI、基因）用留白与侧面描写绕开，写错的硬伤会被读者抓住并失去信任。
- 社会推演是科幻的半壁江山：技术改变了婚姻、货币、战争、死亡的形态吗？推演得越彻底，世界越立体。

## 四、子类型差异

- 末世求生：重点在秩序崩塌后的人性实验——资源、信任、规则的重建比丧尸更吓人。末世前期（崩塌进行时）的恐慌质感与中期（据点时代）的经营质感截然不同。
- 星际/太空歌剧：尺度感是第一难题——用通讯延迟、航程时长、代际更替让"大"可感；星际战争写后勤与政治多写舰炮对轰。
- 赛博朋克：核心是"高科技、低生活"的撕裂——义体改造的阶层鸿沟、巨型企业替代政府的秩序。视觉风格（雨、霓虹、义眼）服务于这层批判，而非装饰。
- 近未来科技惊悚：AI、脑机接口、生物编辑的失控就在门外，恐惧来自"这真的会发生"。

## 五、人文内核

- 科幻追问的问题要古老：爱、死亡、自由、何以为人——技术只是提问的新方式。主题先行不等于说教，让答案从人物的抉择中浮现。
- 非人角色的塑造是科幻的独门功课：AI、克隆体、异星生命的行为逻辑要与人类形成对照，"像人的机器"与"像机器的人"各有各的震撼。
- 科幻的悲观与乐观都要有出口：绝望设定下的一线人性微光，或乌托邦代价的揭示，避免纯粹的技术崇拜或末日展览。

## 六、套路与反套路

- 时间线诡计（时间旅行、循环、多世界）要提前立规矩：能改什么、不能改什么，规则外的巧合是灾难。
- 警惕"科学家的疯狂"与"军方的一意孤行"这类懒惰反派动机，冲突的根源应是立场与利益的结构性对立。
- 降维打击式结局（突然出现碾压性力量解决一切）是科幻文最泄气的收尾，主角的胜利必须建立在前文埋下的规则与代价之上。
