# 灵异创作指导

这是灵异（含惊悚、神鬼志怪）类型小说的专项创作要求，作为通用叙事心法的补充。通用原则（展示而非告知、章末钩子、视角锚定等）仍然适用，以下聚焦灵异特有的要点。

## 一、恐惧的机制

恐惧来自未知与失控，而非血腥与跳吓。

- 恐惧的公式：日常的裂缝 + 无力感。诡异渗入熟悉场景（电梯多出一层、合影里多了个人）比废弃医院更吓人——安全感被侵蚀的过程就是恐怖本身。
- "规则"是灵异文的核心装置：诡异有规则（不能回头、天亮前离开、镜子里的不能信），规则被逐步发现、验证、利用的过程就是主线。
- 留白胜过展示：怪物完全现身前最可怕。描写诡异用局部、暗示、他人的反应，让读者的脑补完成最后一击。
- 恐惧需要喘息：张弛交替才能维持敏感度，持续高压会让读者麻木。幽默与温情段落不是泄气，是蓄压。

## 二、灵异体系的自洽

- 诡异的强度、行为模式、弱点要前后一致：读者靠积累的规则预测危险，规则作弊一次，恐惧就失效。
- 主角的自保手段要有边界：能看见、能沟通、能请神——每个能力配限制（次数、代价、反噬），全知全能的主角杀死了恐怖。
- 民俗与宗教元素（笔仙、赶尸、萨满、道教科仪）做足功课再用：仪式细节的质感是中式恐怖的韵味所在，也要注意尊重信仰与民俗。

## 三、中式恐怖的美学

- 中式恐怖的内核是"人情纠缠"：执念、报恩、冤屈、因果——鬼是未了之事的化身，恐怖的尽头常是悲情。
- 意象系统是现成的富矿：红嫁衣、纸人、老宅、祠堂、坟村、寿宴——用意象唤起文化记忆里的敬畏。
- 城乡变迁是绝佳的恐怖温床：拆迁的老村、消失的方言、断掉的香火——时代记忆的断裂自带阴气。

## 四、探案结构

灵异文常借用推理骨架：一起起诡异事件 = 一个个案件。

- 每个事件单元要有完整的"起（异象）—查（民俗/线索）—验（规则的代价）—解（超度/破局）—余（未尽的钩子）"闭环。
- 事件背后串一条主线暗河：所有怪谈指向同一根源（某个村子、某代人的罪），单元剧积累成解谜的拼图。
- 恐怖与推理的配比想清楚：侧重"怎么活下来"还是"当年发生了什么"，两条线都可以是主菜但不能都当配菜。

## 五、主角与配角

- 主角要有"不得不"的理由：阴眼、家族宿命、还愿的债——被迫卷入比主动探险更能让读者共情恐惧。
- 师父/同行者类别克制使用：降魔人前辈是双刃剑，太强则恐怖失压——让他受限（辈分规矩、自身难保、半信半疑）。
- 队友的伤亡与变异要敢于下手：灵异文的信任是稀缺资源，"身边的人变得不对劲"是最经济的恐怖。

## 六、套路与反套路

- "最终解释权"式反转（一切都是幻觉/精神病）会清算掉全部恐惧积累，慎用；多层反转至少要留一层真实。
- 警惕网络怪谈的陈词滥调直接搬运（第十三层楼梯、半夜敲门）：老梗要么翻新（规则在现代社会的新变体），要么致敬得巧妙。
- 温情结局与悲剧结局各有拥趸，但都不要突然转向——结局的调性在前文就应埋好线索。
