# 游戏·电竞创作指导

这是游戏、电竞类型小说的专项创作要求，作为通用叙事心法的补充。通用原则（展示而非告知、章末钩子、视角锚定等）仍然适用，以下聚焦游戏电竞特有的要点。

## 一、双线结构

游戏电竞文的骨架是"比赛线 + 生活线"双线咬合。

- 比赛线提供爽感与目标（晋级、复仇、夺冠），生活线提供人物与情感（队友、家庭、职业危机）；只有一条线的作品要么干瘪要么拖沓。
- 两线要互为因果：生活的变故影响比赛状态，比赛的胜负改变人生轨迹。各自独立推进的平行线是结构松散的信号。
- 赛季与赛事体系是天然的卷结构：城市赛→联赛→季后赛→世界赛，每个层级对手升级、赌注加码，充分利用。

## 二、比赛的叙事化

照实复述对局是死路，比赛必须是戏剧而非战报。

- 一场比赛只聚焦 2-3 个关键回合详写：开局试探快写，决胜团战慢镜头——用叙事节奏模拟观赛的呼吸感。
- 比赛的悬念在"局外"：对手研究过主角的战术、队友带伤上场、替补的心理波动——把人性冲突压进对局，技术对抗才有重量。
- 主角不能场场赢：败局的价值往往大于胜局——暴露短板、引爆矛盾、催生蜕变。关键失利要输得有尊严、有收获。
- 解说视角、观众弹幕、对手视角是三面镜子：借它们放大高光时刻的爽感，也借它们制造"外界不知道真相"的反差。

## 三、游戏机制的呈现

- 懂行读者是基本盘：核心机制（版本、装备、战术体系）写得专业，读者才买账。不熟悉的游戏类型要做功课，机制硬伤会被当场指出。
- 术语分寸：圈内黑话增强质感，但首次出现要能从上下文读懂；一章新术语不超过三五个。
- 虚构游戏比真实游戏更自由：自创游戏可以为主角的能力量身定制（微操、意识、指挥），也规避版权与版本变动——但要先花笔墨让读者"学会"这个游戏的基本规则。
- 数值与操作要翻译成画面："APM 三百"不如"他的手指在键盘上敲出了残影，三个编队切换只用了一秒"。

## 四、行业质感

- 电竞文写"职业"而不仅是"打游戏"：训练作息、教练组、数据分析、俱乐部运营、赞助商与转会——行业肌理让故事可信。
- 职业寿命与退役焦虑是电竞文独有的时间压力：十六岁入行、二十四岁"高龄"，选手的每一季都在与时间赛跑。
- 网游文另有一套逻辑：公会政治、经济系统、版本变迁、玩家生态——网游文写的是"一个小社会"，而非一个人的升级。

## 五、团队与群像

- 电竞是团队项目：五个位置的选手性格互补也互相消耗，队内化学反应（磨合、争执、托付）比个人高光更动人。
- 对手值得尊重：宿敌是电竞文的标配资产——棋逢对手的惺惺相惜、赛季交手的宿命感，把"打败他"写成"成全彼此"。
- 教练、经理、陪练、家人构成配角网络：他们让"打游戏"这件事连接到更广阔的人生评价体系。

## 六、套路与反套路

- 天才少年一鸣惊人的开局已高度模板化：给天赋配一个显性短板（心态、沟通、伤病），成长曲线才有的写。
- 警惕"开挂式碾压"：靠版本答案或外挂式的优势连赢，爽感廉价且不可持续；真正的爽点是绝境中的战术创新与团队执行。
- 复仇线（被踢出战队后崛起）要给旧队合理的逻辑：俱乐部的决定有自己的道理，恩怨才有得掰扯，而非脸谱化的坏人当道。
