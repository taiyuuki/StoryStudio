# 悬疑/推理创作指导

这是悬疑、推理类型小说的专项创作要求，作为通用叙事心法的补充。以下聚焦悬疑推理特有的要点，尤其是"信息控制"这一核心技巧。

## 一、线索公平性（推理铁律）

本格推理的核心契约：读者拥有与侦探同等的机会去解开谜题。

- 关键线索必须在真相揭示前出示给读者，不能在解谜时突然掏出从未提及的信息（"天降线索"是大忌）。
- 线索可以伪装、可以埋在不显眼处、可以与其他信息混在一起，但不能隐藏。让真相"回头看得见"而非"突然冒出来"。
- 如果是变格/社会派，可以放宽公平性，但仍需保证逻辑自洽——真相要有铺垫，不能反常识硬掰。

## 二、信息揭露的节奏

悬疑的本质是"不知道"的张力，信息揭露的时机决定成败。

- 分层揭露：不要一次性倾倒所有真相。每解开一层，抛出更深的疑问（"为什么他要撒谎？"→"因为他在保护某人"→"保护的人已经死了"）。
- 红鲱鱼（误导线索）要用得克制：1-2 条精心设计的误导胜过满天飞的假线索。误导要有逻辑基础（看似合理实则另有隐情），而非单纯为了骗读者。
- 控制视角信息量：POV 角色不知道的事，叙述中就不能泄露。读者应与主角一起困惑、一起接近真相。

## 三、悬念递进结构

- 每章至少埋一个疑问或抛出一个危机，保持"我还想知道接下来"的牵引力。
- 大悬念（谁是凶手/真相是什么）贯穿全书，小悬念（这章的危机/角色的秘密）逐章解决又不断产生。
- 危机升级：从"奇怪的事"到"有人在暗中行动"到"生命受到威胁"到"真相逼近"，张力要持续上升而非平铺。

## 四、真相收敛的逻辑自洽

- 真相揭示时，所有此前看似矛盾或无关的细节都应各归其位。读者回看时应有"原来如此"的恍然，而非"这说不通"的困惑。
- 避免机械降神：解谜靠的是已建立的线索和逻辑，不是突然出现的新角色、新能力或巧合。
- 凶手/幕后黑手要是"有可能的人"：不能是开场才出现的路人，也不能是全程毫无可疑的完美好人（除非有极强的理由）。

## 五、不可靠叙述者（进阶技巧）

- 通过视角角色的认知偏差、记忆错误、主观滤镜来误导读者，是高级悬疑手法。但要给读者留下"哪里不对"的细微线索。
- 不可靠要有限度：不能最后说"前面全是你骗我的"——读者会感到被背叛而非被惊艳。合理的不可靠是"角度不同"，而非"刻意撒谎"。

## 六、推理硬伤规避

这些是悬疑推理的常见致命伤：

- 时间线矛盾：务必用工具记录角色何时何地、知道什么。角色不可能同时出现在两地，也不可能知道他不该知道的事。
- 动机不足：凶手为什么要这么做？动机要有说服力，"因为他是疯子"是最差的答案。
- 手段不合理：犯罪手法在物理、技术、心理上要站得住脚。涉及专业知识（法医、网络、化学）时要做功课或模糊处理，不要写外行话。
- 角色降智：为了让剧情推进而让聪明的角色犯低级错误，读者会出戏。角色的失误要符合其性格和当时的认知局限。

## 七、氛围与恐惧

- 悬疑的恐惧来自"未知"和"逼近"，而非血腥描写。暗示比直写更有效：门缝下的光、不该出现的声音、消失的物品。
- 安全感与危险感交替：让角色（和读者）以为安全了，再打破它，比持续的紧张更有冲击力。
