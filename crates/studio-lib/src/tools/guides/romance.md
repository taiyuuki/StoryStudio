# 言情创作指导

这是言情类型小说的专项创作要求，作为通用叙事心法的补充。言情的核心是"情感"——两个人（或更多人）之间关系的产生、发展、波折与升华。以下聚焦言情特有的要点。

## 一、CP 化学反应

读者追的是"想看他们在一起"的渴望，这建立在化学反应之上。

- 初见要有记忆点：不是俗套的撞怀/对视，而是一个能定义两人关系的瞬间——一句对话、一个误会、一次意外的默契或冲突。
- 互动要有张力：不只是甜，更要有"推拉"。价值观的碰撞、性格的反差、立场的对立，让每一次接触都有火花。
- 化学反应靠细节：眼神停留的时长、无意识的小动作、记住对方随口说的话——比直接写"他心动了"有力一百倍。
- 区分"喜欢"和"在意"：在意的表现更微妙（忍不住关注、因对方而改变习惯、为对方破例），也更能打动读者。

## 二、情感张力曲线（甜虐节奏）

全程甜会腻，全程虐会累，张弛有度才是好节奏。

- 甜虐配比因人而异，但要有起伏：一段甜蜜后要有危机，一次虐心后要给希望。读者需要喘息，也需要被撩拨。
- 虐要有根源：误会、身份、外部阻力、性格缺陷——虐的理由要合理，不能为虐而虐。最差的虐是"明明说清楚就好了却偏不说"。
- 虐的强度要与情感深度匹配：刚认识就死去活来显得假；感情越深，虐才越痛。
- 甜点要具体：不是"他们很幸福"，而是一个只有他们懂的梗、一个笨拙的照顾、一个下意识的保护。

## 三、心理与细节描写

言情的重头戏在内心，但"想"不能替代"做"。

- 情感通过生理反应和行为折射：心跳、脸红、手足无措是浅层；为他改变决定、克制不说的话、深夜的辗转是深层。
- 内心独白要克制：不要让角色在心里反复念叨"我好喜欢他"。让读者从行为推断情感，比角色自白更有代入感。
- 对话是言情的利器：暧昧期的试探、吵架时的口是心非、和好时的欲言又止——对白承载情感的信息密度最高。

## 四、误会冲突的合理性

误会桥段是言情必备，但最容易翻车。

- 误会的根源要合理：信息不对称、性格导致的沟通障碍、外部势力的挑拨——都可以；但"就是不肯问一句"是偷懒。
- 误会要有时效：不要让一个本可一句话解决的误会拖十章。要么让它升级（牵出更深的问题），要么尽快解开再制造新冲突。
- 最好的冲突不是误会，而是真实矛盾：价值观差异、人生选择的分歧、身份立场的对立——这些解不开的结比假误会更揪心。

## 五、情感高潮设计

- 表白/确认关系/重逢/牺牲——这些高光时刻要有铺垫。前面所有的细节都在为此刻蓄力，高潮时一两个呼应就能引爆情绪。
- 高潮不是"突然很感人"，而是"前面所有的克制在这一刻释放"。一个一直隐忍的角色终于说出心意，比一个天天表白的人说"我爱你"震撼得多。
- 给读者"苦尽甘来"的满足感，但不要把所有问题瞬间解决——留一些真实的余味。

## 六、人设要点

- 男主/女主要有立体感和成长。完美的"霸总"或"白莲花"已经过时，读者要的是有缺陷但有魅力的真实的人。
- 配角不能只是工具人：情敌要有自己的感情线，闺蜜要有自己的性格。扁平的配角会让整个情感世界显得假。
- CP 之间要有"专属感"：他们对彼此而言是特别的，这种特殊性通过只有他们才懂的互动体现，而非通过旁人强调。

## 七、分清言情亚型

不同亚型侧重点不同，创作时要明确：

- 现代都市言情：贴近现实，重情感逻辑和人物成长，忌悬浮。
- 古代言情：可融入宅斗、宫斗、权谋元素，但情感仍是主线。
- 甜宠：低虐高甜，重日常互动和撒糖节奏，但要避免无脑甜。
- 虐恋：重情感张力和命运感，但虐要有意义、有出口。
