# 轻小说创作指导

这是轻小说类型小说的专项创作要求，作为通用叙事心法的补充。通用原则（展示而非告知、章末钩子、视角锚定等）仍然适用，以下聚焦轻小说特有的要点。

## 一、轻小说的语法

轻小说是"角色驱动 + 高概念设定 + 网感文风"的组合，节奏与画风自成一派。

- 一句话高概念先行："关于我转生变成史莱姆这档事"式的前提本身就是卖点——开篇尽快把有趣的核心设定亮出来，别藏。
- 文风轻快、句短、对话密：吐槽与内心独白是轻小说的呼吸法，叙述段落超过五行就该警惕。
- 章节体量小而快：每章一个明确的事件或反转，卷末大高潮。轻小说读者要的是"顺畅地翻完"的体验。
- 二次元浓度是特性而非缺陷：人设标签（傲娇、天然、病娇）是读者的快捷入口——但要在标签之下埋反差与成长。

## 二、角色即一切

轻小说的成败七分在角色。

- 主角要有清晰的"相对性"：要么是吐槽担当的普通人（读者视角），要么是有致命短板的奇才（成长弧线）——全能主角在轻小说里不讨喜。
- 女主/男主要立体分工：每个主要角色有独立的动机线与高光章节，人气角色的比重随读者反馈动态调整是连载智慧。
- 组合的化学反应大于单个角色的魅力：冤家、损友、主仆的反差搭配，对话的攻防节奏是轻小说最好看的部分。
- 反派要"有梗"：轻小说的反派常带滑稽或悲情底色，纯粹的恶没有市场；被打败的方式也要有趣。

## 三、世界观与设定

- 设定为角色服务：异世界、学园、游戏系统都只是让角色相处的舞台装置，设定自嗨是轻小说扑街首因。
- "异世界转生/穿越"要找新角度：金手指的形态（只能吐槽、只有商店系统、带着前世记忆的咸鱼）比世界观本身更能区隔作品。
- 系统流的轻小说写法：系统是吐槽对象或养成导师，拟人化的系统自带角色魅力。
- 魔法/异能体系视觉化、规则化：招式名要有记忆点，能力的边界要清晰——战斗戏在轻小说里是回合制的策略游戏，不是修罗场。

## 四、情感与日常

- 日常章是轻小说的本体之一：文化节、温泉、考试、做饭——日常事件写人物关系的变化，糖点与刀点交替。
- 恋爱线要"将暧昧进行到底"：确认关系前的拉扯是最大卖点，重要节点（告白、牵手）值得用整卷经营；后宫或单女主的路线尽早定型，避免读者分裂。
- 吐槽是安全的情感表达：用吐槽包裹害羞、用毒舌表达关心——轻小说的情感修辞学。

## 五、日系翻译腔的取舍

- 轻小说的文体天然带日系翻译腔（语气词、敬语梗、夸张比喻）：保留其轻快感，但要控制频率——通篇"诶——""呜哇"会腻。
- 中文轻小说可以发展本土化语感：网络流行语的时效性注意保鲜期，三年后读仍不尴尬的分寸。
- 章节标题是表演区：吐槽式长标题（"关于XXX这件事"）是传统艺能，但同一句式不要连用超过三次。

## 六、套路与反套路

- 龙傲天与"无意识后宫"要节制：主角的魅力要让读者信服（具体的事件赢得），而非世界观强行降智配合。
- 转生开局的"原作知识"是易耗品：剧情偏离原作后怎么办要想好，多数作品死在这个断供点上。
- 每卷一个新角色/新势力的"膨胀螺旋"要有退出机制：旧角色轮换休息，新人不挤占核心组的戏份。
